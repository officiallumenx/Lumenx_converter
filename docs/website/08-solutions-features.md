## 1. Audiences (sections)

| Audience | Outcome | Products |
|----------|---------|----------|
| Principal / office | Run the institute day without chasing notebooks | Admin |
| Parent | See attendance, fees, and the bus without calling the office | Connect (+ Transport) |
| Teacher | Mark attendance and share class work on a phone | Connect |
| Driver / transport in-charge | Execute the trip from a dedicated app | Transport |
| Group / trust | License, trial, and health across institutes | Nexus |

Each audience: 3 bullets + link to the relevant product page.

## 2. Feature catalog (modules)

Use the live module list from Master §5, grouped for a buyer:

Students, Teachers, Parents, Attendance, Notifications  

**Growing institute**  
Fees, Exams, Timetable, Complaints, Announcements & events, Analytics, Admissions  

**Add-on / advanced**  
Transport, Careers, Certificates, IAM / custom permissions, Alerts  

Public copy: modules are **switched on per institute** (Nexus). Do **not** map them to Core/Plus/Max price cards. If asked, “Your LumenX operator enables the modules you need; billing is per student, not per module pack.”
