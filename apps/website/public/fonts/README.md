# LumenX Website Typography

## Inter Variable (Headings & Body)

Self-hosted via the npm package `@fontsource-variable/inter`.

- Loaded from `node_modules` by the LumenX build pipeline (WOFF2 + `font-display: swap`).
- Configured in `src/layouts/Layout.astro`, `src/styles/typography.css`, and `tailwind.config.cjs`.
